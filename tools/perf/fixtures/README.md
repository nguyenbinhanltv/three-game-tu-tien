# Fixture cho `pnpm compat`

- `2d_etc1s.ktx2`, `2d_uastc.ktx2`: texture KTX2 nén Basis (ETC1S và UASTC) lấy nguyên từ three.js r178
  (`examples/textures/ktx2/`, giấy phép MIT, © three.js authors). Chỉ dùng để thử transcoder Basis
  của `KTX2Loader` trên từng trình duyệt; không vào bản build game.
