# P2-B4 — Cảnh độ kiếp kịch tính

Ảnh 2, 6, 7 chụp bằng Chrome thật (WebGPU, RTX 3060 Ti); ảnh 1, 3, 4, 5 chụp lượt trước bằng Chromium headless (WebGL2), `?mute=1`, `?god`, `/gm level 15` + `/gm xp` + `/gm give itm_truc_co_dan`, bấm độ kiếp.

1. `1-truoc-do-kiep.png`: trước khi độ kiếp (màu thường).
2. `2-may-xoay-letterbox.png`: 6 giây đầu, ngẩng camera hết cỡ (tele 95°) thấy hai tầng mây kiếp xoáy, ba cánh xoắn ốc và mắt bão tím; letterbox mỏng, nhãn 3D ẩn, màu chìm tối/tím.
3. `3-mau-toi-tim.png`: giữa kiếp, tông tối/tím toàn cảnh.
4. `4-set-danh.png`: tia sét đánh theo vùng báo trước (chớp + rung camera).
5. `5-preset-thap.png`: cùng cảnh ở preset Thấp.
6. `6-khoanh-khac-dot-pha.jpg`: vừa đột phá: quầng vàng ấm tỏa từ người và chùm tia nắng xòe lên (cộng sáng, mảnh), màu cảnh giữ nguyên.
