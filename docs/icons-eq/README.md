# Icon trang bị (28 món)

Dựng thủ tục bằng Blender (`tools/icons/render_equipment.py` + `equipment.mjs`), không dùng Tripo. Atlas `icons.json` nới 8×9, ô cũ giữ nguyên chỗ. Phối màu bộ theo `sets.json`: Lạc Kiếm ngà+lam, Huyền Giáp đen+đồng, Đan Tâm ngọc bích+vàng nhạt, Hàn Giao Lân bạc băng+lam ngọc.

- `tui-do.webp`, `tui-do-da-mac.webp`: túi đồ đủ icon mới, một số món đã mặc (`pnpm shots:eqicons --out ../../docs/icons-eq`, Chrome GPU thật, tắt tiếng).
- `bang-nhan-vat.webp`: bảng nhân vật (C) với tooltip bộ Lạc Kiếm.
